To install one

  1. In duskcode open Plugins, then Workshop.
  2. Search the item's name.
  3. Read what it may access, then Install.

What the app checks before it installs anything

The list is signed
The list of this page is signed with a key built into duskcode. A list changed on the way is refused.
Every package is checked
Each package has its size and SHA-256 in the signed list, and unpacks only into its own folder.
You see what it may do
A plugin's permissions are shown before it is installed. An update that asks for more is switched off until you allow it.
Your keys stay yours
A plugin's own token is put into its requests by duskcode, only for the site it was given for.

Official is work by duskcode. Verified is somebody else's work, checked and signed here. Other companies' names say only what an item works with; duskcode is not affiliated with or endorsed by them.
