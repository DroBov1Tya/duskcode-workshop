The Workshop of duskcode

Plugins, skills, packs and agents. A plugin runs in its own sandbox, sees none of your keys and reaches only the sites it names; skills and agents are text.

Install in duskcode

  1. Open Plugins, then Workshop.
  2. Search the item's name.
  3. Read what it may access, then Install.

This page installs nothing. The app checks the signed list and every package itself.

How it works

The app checks every item before it installs one.

Signed list

The list of this page is signed with a key built into duskcode. A list changed on the way is refused.

Checked package

Every package has its size and SHA-256 in the signed list, and unpacks only into its own folder.

What it may do

You see a plugin's permissions before it is installed. An update that asks for more is switched off until you allow it.

Your keys stay yours

A plugin's own token is put into its requests by duskcode, only for the site it was given for.
